# Algo Trade Lab API

Backend of [Algo Trade Lab](https://github.com/advay-sinha/Algo-Trade-Simulator): backtesting with costs and risk analytics, leakage-free ML training, research memory, and a tool-calling research copilot. Everything is paper trading — no real orders.

This Space is deployed automatically from the GitHub repository; edit the code there, not here. The interactive frontend is served separately and talks to this API under `/api` (health check: `/api/health`, OpenAPI docs: `/api/docs`).
